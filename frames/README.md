# الإطارات (frames)

كل إطار = ملف + سطر في `frames.json`. التطبيق يجلب `frames.json` ويعرض الإطارات في المتجر،
وعند الشراء والتفعيل يظهر الإطار حول صورة المستخدم في المتصدرين والملف الشخصي.

الصيغ المدعومة في حقل `file`:
- **`.json`** — أنيميشن Lottie (يُشغَّل تلقائياً في حلقة لا نهائية) ← الموصى به
- `.webp` / `.gif` متحرك، أو `.png` ثابت

```json
{ "id": "neon-ring", "name": "حلقة النيون", "en": "Neon Ring",
  "file": "neon-ring.json", "price": 120, "scale": 1.4 }
```

- `id`: معرّف فريد لا يتغيّر بعد النشر (تُحفظ به مشتريات المستخدمين).
- `price`: السعر بالنقاط. `scale`: حجم الإطار نسبةً لقطر الصورة (1.0–2.0).

## نصائح لملف Lottie
- اجعل التركيبة مربعة (مثل 200×200) والإطار حلقة شفافة في الوسط، حتى تظهر الصورة داخله.
- استخدم Shape Layers فقط (تجنّب المؤثرات Effects/Expressions والصور المدمجة الثقيلة)، واجعل الحجم أقل من ~100KB.
- يجب أن تكون الحلقة سلسة (أول إطار = آخر إطار) لأنها تُعاد بلا توقف.
